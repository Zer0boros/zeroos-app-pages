Support — zeroOS for iPhone

Last updated: Sunday, 15 November 2026 (CET)

First place to ask

Contact the person who runs your zeroOS server (your server admin). They control the server, invitations, and device approvals.

What the iPhone app needs

  1. A zeroOS server that you or your admin run — make sure the computer is on and zeroOS is running
  2. The private Tailscale network built into the app (no separate networking app to install)
  3. An invitation from that server
  4. Admin approval of this phone’s device key
  5. Face ID, Touch ID, or device passcode when the app asks you to confirm

The app does not replace the server. Without a zeroOS server to join, there is nothing to connect to. The app is free, and the server software is planned to be open source.

Tips when something fails

  • Can’t reach zeroOS — make sure the server computer is on and zeroOS is running, then try again from the phone.
  • Invitation problems — ask for a fresh invitation; codes and links can expire or be single-use.
  • Waiting for approval — the admin must approve this device on the server.
  • A request was blocked — the server’s prompt filter may have refused the text of the prompt. This filter is on by default and is controlled by the server admin. It is not image moderation.
  • Bad response — on a supported server, you can report a Bad response from the app. The report stays on that server for its admin and does not attach the message, prompt, or image.
  • Sign out — clears sign-in on this iPhone only; it does not delete the account on the server.
  • Remove server — removes this phone’s saved connection for that server; content on the server stays. Ask for a new invitation to add the server again. iPhone backups do not restore servers.
  • Delete account — on a supported server, Delete account in the app removes your account and its content on that server. It does not remove backups the server owner may have made, or Tailscale’s logs. On an older server, this option is unavailable; contact the admin.

Privacy

Sign out and Remove server are not account deletion. Read the Privacy Policy.
