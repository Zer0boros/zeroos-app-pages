Support — zeroOS for iPhone

Last updated: Monday, 9 November 2026 (CET)

First place to ask

Contact the person who runs your zeroOS Mac (your server admin). They control the server, invitations, and device approvals.

What the iPhone app needs

  1. A Mac running the zeroOS server — make sure the Mac is on and zeroOS is running
  2. Private networking built into the app (no separate networking app to install)
  3. An invitation from that server
  4. Admin approval of this phone's device key
  5. Face ID, Touch ID, or device passcode when the app asks you to confirm

The app does not replace the Mac server. Without your own zeroOS server there is nothing to connect to.

Tips when something fails

  • Can’t reach zeroOS — make sure the Mac is on and zeroOS is running, then try again from the phone.
  • Invitation problems — ask for a fresh invitation; codes and links can expire or be single-use.
  • Waiting for approval — the admin must approve this device on the Mac.
  • Sign out — clears sign-in on this iPhone only; it does not delete the Mac account.
  • Remove server — removes this phone's saved connection for that server; chats on the Mac stay. Ask for a new invitation to add the server again. iPhone backups do not restore servers.

What we are not claiming yet

Features that are not on this phone yet are labeled that way in the app. Do not expect unfinished admin approval screens to work from the phone.

Privacy

Sign out and Remove server are not account deletion. Read the Privacy Policy.
