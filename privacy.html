Privacy Policy — zeroOS for iPhone

Last updated: Sunday, 15 November 2026 (CET)

Who this is for

zeroOS for iPhone ("the app") is a free companion app published by Daniel Petcu as an individual. It connects only to a zeroOS server that you or your admin run yourselves. The publisher does not operate a cloud service for the app and does not receive your chats, images, or other user content. The server software is planned to be open source.

Who holds what

Three roles matter:

  • The app publisher (Daniel Petcu) distributes the iPhone app. The publisher does not host your account or receive your content.
  • The server operator is the person who runs the zeroOS server you join. Your account and content live on that selected server.
  • Tailscale provides the private network used to reach that server. It can see connection metadata, as described below, under Tailscale’s privacy policy.

Data stored on the selected server

The selected zeroOS server stores your account details, sign-in and access records, and your account’s own content, including chats, projects, files, images, Memory, and BioVault data if you have enabled it. That content is kept on the server so the product can work; there is no blanket automatic expiry. The publisher does not receive this content.

How the app connects

The app uses Tailscale, built into the app, to reach the selected server. To operate the network, Tailscale can see device and node identifiers, IP addresses, connection timing, and some device and software information. How long Tailscale keeps that information is up to Tailscale, not the app publisher. See Tailscale’s privacy policy.

Your chats and images are not sent to the app publisher. Connection metadata used to reach the server is described above and is separate from that content.

Device key and enrollment

Each iPhone uses its own device key. Enrollment starts from an invitation created on the server. Sign-in does not finish until the device is approved for that server.

Face ID / device passcode

When the app asks you to confirm with Face ID, Touch ID, or your device passcode, that check happens on the iPhone. zeroOS does not receive your biometric templates.

Saved servers on the phone

The app may store server connection details, credentials needed to reach your server, and cached data on this iPhone so you can reconnect. Removing a server deletes that phone-side material for that server. It does not delete content stored on the server.

Sign out, Remove server, and account deletion

  • Sign out clears this server’s sign-in on this iPhone. It is not account deletion.
  • Remove server removes saved connection, credentials, and cached data for that server from this iPhone. Content on the server is not deleted. Server-side access may still exist until an admin revokes it.
  • Delete account is available in the app on a supported zeroOS server. It removes the selected account and its associated content on that server, and clears this phone’s data for that account. It does not delete backups the server owner may already have made, copies on other devices, or Tailscale’s logs. Those are separate. If the server is older and does not support in-app deletion, contact its admin.

Bad response reports

On a supported server, you can report a Bad response from the app. The report stays on that server for its admin. It does not attach the message, prompt, or image, and it is not sent to the app publisher. Deleting the reporting account removes its reports from that server.

Prompt filter

The selected server uses a text prompt filter, which is on by default for every account. It checks the text of chat and image prompts before generation. The server admin can turn it off for an account. It is not image moderation, and it cannot guarantee that every harmful or evading request is blocked.

Advertising, tracking, and analytics

The app has no ads, tracking, or analytics.

Children

The app is intended for people who operate or are invited to a private zeroOS server. It is not directed at children.

Contact

For server or access issues, contact the person who runs your zeroOS server. For product privacy questions about the iPhone app listing, contact zig4samura@gmail.com.
