About — zeroOS for iPhone

Last updated: Sunday, 15 November 2026 (CET)

zeroOS for iPhone is a free companion app for a zeroOS server that you, or an admin you trust, run yourself. It is published by Daniel Petcu as an individual. It is not a standalone chatbot, and the publisher does not run a cloud service for your chats or images.

The app connects only to the zeroOS server you select. Content you create stays on that server. The server software is planned to be open source so that anyone can run it.

The connection uses Tailscale, which is built into the app. Sign-in does not finish until the device is approved for that server.

Read the Privacy Policy and Support pages for details. For product questions about the iPhone app listing, contact zig4samura@gmail.com. For server or access issues, contact the person who runs your zeroOS server.
